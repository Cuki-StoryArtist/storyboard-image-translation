# 故事板图片翻译默认术语

这些译法用于故事板艺术家、动画和影视前期语境；根据原句和画面调整语序，不做机械替换。

| English | 默认中文 | 使用提示 |
|---|---|---|
| storyboard | 故事板 | 按用户偏好保留“故事板”，不要改成“分镜” |
| storyboarding | 故事板创作 / 故事板绘制 | 讲流程时用“创作”，讲动作时用“绘制” |
| storyboard artist | 故事板艺术家 | 人物身份或作者简介 |
| shot | 镜头 | 电影/动画镜头；不要泛译为“拍摄” |
| cinematic language | 电影语言 | 讲视觉叙事系统时使用 |
| cinematic shot / composition | 电影化镜头 / 镜头构图 | 按上下文选择 |
| composition | 构图 | 强调画面组织和视觉重点 |
| staging | 场面调度 / 调度 | 角色、道具和空间的组织 |
| flat staging / flat shot | 平面调度 / 平面镜头 | 不带贬义；结合上下文说明其表达作用 |
| camera as a character | 把摄影机当作一个角色 | 强调摄影机的情绪和叙事立场 |
| foreground elements | 前景元素 | 用于遮挡、框景、压迫感和空间层次 |
| frame device / framing | 框景手法 / 框景 | 不必直译为“框架设备” |
| set / background | 场景 / 背景 | set 偏场景空间，background 偏画面背景 |
| horizon line | 地平线 | 透视、机位和视平线讨论 |
| vanishing point | 消失点 | 透视线汇聚位置 |
| high angle / low angle | 高机位 / 低机位 | 若原文讨论视线高度，也可译“俯拍/仰拍” |
| Dutch angle / tilted camera | 荷兰角 / 倾斜机位 | 按作者语气选择，避免“歪镜头” |
| wide shot / medium shot / close-up | 全景 / 中景 / 近景（或特写） | 按画面实际景别统一 |
| eyeline | 视线高度 / 视线 | 讲人物视线或轴线时保持明确 |
| blocking | 走位 / 调度 | 角色在空间中的行动安排 |
| depth / spatial relationship | 空间深度 / 空间关系 | 兼顾透视和角色关系 |
| silhouette | 剪影 / 轮廓 | 看语境选择，不要一律译成“影子” |
| visual storytelling | 视觉叙事 | 讲画面如何传达未明说的信息 |
| symbolism / metaphor / allegory | 象征 / 隐喻 / 寓意 | 依次对应概念，勿混为“比喻” |
| intent / intention | 意图 / 叙事意图 | 讲每个镜头想表达什么 |
| emotional response | 情绪回应 / 情绪反应 | 讲摄影机或画面对场景的感受 |
